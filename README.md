# Labesny — app preview

The Labesny app, built for the web so it can be opened on a phone without installing anything.

**https://band-agents.github.io/labesny-app-preview/**

On an iPhone, open it in Safari, tap Share, then "Add to Home Screen": it then opens like an app,
without Safari's address bar. On Android the same works from Chrome's menu.

This is the same code as the Android app, compiled for the browser. It is a way to show the app
before Apple's side is set up — the real iOS build still needs FIG's Apple Developer account.

Built from `band-agents/labesny`; do not edit anything here by hand.
